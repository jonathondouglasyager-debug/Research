# Research

A personal investigative research platform combining Python automation with a browser-based command center.

## Components

### Python Backend

- **`_System/`** — Core system: file indexing, agent management, source registry, automated sync
- **`_Automation/`** — Research automation: entity extraction, timeline generation, knowledge graphs
- **`_Generation/`** — Content generation: report building, analysis outputs

### HTML Frontend

- **`INDEX.html`** — Main command center for navigating research files and viewing dashboards
- Multiple versioned interfaces (`INDEX_v1` through `INDEX_v5`) with progressively richer features

## Getting Started

### Prerequisites
- Python 3.10+
- A modern web browser

### Usage
1. Open `INDEX.html` in your browser to access the command center
2. See [QUICK_START_GUIDE.md](QUICK_START_GUIDE.md) for detailed usage instructions
3. See subdirectory READMEs (`_System/README.md`, `_Automation/README.md`, `_Generation/README.md`) for component-specific documentation
